## 🎨 Features

**🍦 Interactive Menu**
Filter cones, scoops, sticks, family packs & specials.

**🛒 Shopping Cart**
Add, remove and manage items with automatic price calculation.

**🌙 Theme Switcher**
Beautiful light/dark mode with saved preferences.

**🎁 Special Offers**
Animated offers with a live countdown timer.

**🖼️ Gallery**
Interactive gallery with lightbox, navigation & touch gestures.

**⭐ Reviews**
Animated customer testimonial slider.

**📅 Table Booking**
Interactive reservation form with validation.

**✨ Smooth UI**
Particles, floating elements, hover effects, scroll animations & parallax.
